# Objects and Decisions

Web 4: [Homework 4](https://in-info-web4.luddy.indianapolis.iu.edu/~karia/newm-n220/homework-four/objectsDecisions.html)

## Instructions

For this homework assignment you will implement javascript to solve various problems.

To complete this homework, complete the following:

1. Create a folder called homework-four.
2. Download the [beginning html file](https://iu.instructure.com/courses/2402404/files/206751112?wrap=1) and place it in your folder.
3. Create a separate javascript file and link it to the html page.
4. Upload your project to the web 4 server.
5. Submit your web 4 server link/URL for the assignment submission.
