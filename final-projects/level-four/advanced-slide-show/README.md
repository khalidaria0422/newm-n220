# Advanced Slide Show

Web 4: [Level 4 — Project 1](https://in-info-web4.luddy.indianapolis.iu.edu/~karia/newm-n220/final-projects/level-four/advanced-slide-show)

## Instructions

For this project, you will create a self-running slideshow that has the following functionality:

- Previous button to look at the previous picture
- Next button to look at the next picture
- Pause/Play button that will alter images depending on if it is in play/pause mode.
- A drop down that has different timing options for the self-running slideshow.
- It must have at least 10 pictures.

NOTE: This project uses timing functions which we have not talked about in class. You will have to research this on your own to complete this project.
