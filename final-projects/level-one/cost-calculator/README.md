# Cost Calculator

Web 4: [Level 1 — Project 2](https://in-info-web4.luddy.indianapolis.iu.edu/~karia/newm-n220/final-projects/level-one/cost-calculator)

## Instructions

One of your first assignments was to do a cost calculator. This calculator will figure in a discount code. For this project you will need to create two input elements:

- Price
- Discount Code

**Discount Code:** You will create three possible discount codes, each with different values. For example:

- SAVE20: 20%
- JOLLYDAYS: 15%
- HOLIDAY10: 10%

The user will type in the character-based discount code. This cannot be a drop down and cannot be a numeric entry.

When the user clicks the "New Price" button, a paragraph will display the new price, factoring in the discount AND a 7% tax. You will also display the amount saved.

```text
- Input: 24.99 and JOLLYDAYS
- Result: Your Total: $22.72
  You saved $2.26!
```
