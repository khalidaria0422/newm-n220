# Regular Expression Replacement

Web 4: [Level 1 — Project 5](https://in-info-web4.luddy.indianapolis.iu.edu/~karia/newm-n220/final-projects/level-one/regular-expression-replacement)

## Instructions

Using regular expressions, replace all the hollys with jollys, and all the jollys with hollys - indpendent of case. When a user clicks the "Replace" button, the text will be changed.

- hollylights.html
- jollyOrnaments.html
- ChristmasHollyVillage.html
- jollyHollyWreath.html

Note: The casing (uppercase or lowercase) must remain the same.

```text
- Original: jollyHollyWreath.html
- Result: hollyJollyWreath.html
```
