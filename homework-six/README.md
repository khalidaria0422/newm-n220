# Debugging

Web 4: [Homework 6](https://in-info-web4.luddy.indianapolis.iu.edu/~karia/newm-n220/homework-six/RPSG.html)

## Instructions

For this homework assignment, you will debug a javascript assignment. You will use all your debugging skills to play a simple rock, paper, scissors game.

To complete this homework, complete the following:

1. Create a folder called homework-six.
2. Download the following two files and place in the homework-six folder.
   1. [HTML file](https://iu.instructure.com/courses/2402404/files/206751133?wrap=1)
   2. [JS file](https://iu.instructure.com/courses/2402404/files/206751144?wrap=1)
3. Debug the assignment until you get it to work. You CANNOT rewrite entire lines/blocks of code. You will make simple changes to make this work.
4. NOTE: Changes will be needed in both html and javascript files.
5. Upload your project to the web 4 server.
6. Submit your web URL for the assignment submission.
